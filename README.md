#🐚***cshell***🐧

AN INTERACTIVE LINUX SHELL WRITTEN PURELY IN C

#***overview***

->can execute any linux command 
->interactive 
->constantly shows the working director

#***Installation***
```bash
git clone https://github.com/premharsha970-png/simple-c-shell.git
gcc -o myshell myshell.c
./myshell
```

#***quick start***
```bash
echo "the shell is working"
ls
pwd
```
