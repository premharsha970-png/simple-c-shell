# simple-c-shell
a simple c shell written on libraries,made for people who don't know linux and made to be user friendly

**libraries included**
libs included 1.stdio.h  : for standard input
              2.stdlib.h : for basic utlities
              3.string.h : for comparing commands to input
              4.unistd.h : for basic system utilities

 **description**
 the program uses a while loop to continuously take input from user.
 the if-else ladder compares the input to a list of commands and gives out puts based on them 
  **further improvements are on their way and forgive me if the documentation sucks this is my first project :) **
